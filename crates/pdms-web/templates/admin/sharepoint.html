Storage

{% if st.backend_locked %}

The configuration file sets where files are stored ([storage] backend), so it can't be switched here. To switch it here instead, remove that line from config/pdms.toml and restart PDMS.

{% else if st.storage.on %}

Turning storage off stores new document files on this server again. The {{ st.storage.sharepoint_files }} file{% if st.storage.sharepoint_files != 1 %}s{% endif %} already in SharePoint stay there, but PDMS can no longer open them until storage is turned back on. To confirm, type the site address.

{% else if st.storage.local_files > 0 %}

{{ st.storage.local_files }} document file{% if st.storage.local_files != 1 %}s are{% else %} is{% endif %} stored on this server. PDMS can't read them once SharePoint storage is on, so storage can only be turned on before documents are added. On a test server, reset it first (docs/SHAREPOINT_SETUP.md).

{% else %}

Turning storage on stores every new document file in the saved site. PDMS tests the site first, and adds its columns and folders when it stores the first file.
