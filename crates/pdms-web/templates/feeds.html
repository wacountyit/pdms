A subscription gives Outlook (or any calendar app) a private web address that shows review, renewal, and expiration dates. It always shows what you can currently see, never includes Restricted documents, and stops working the moment you revoke it.

In Outlook: Add calendar → Subscribe from web (or From internet), then paste the address. Treat the address like a password.
