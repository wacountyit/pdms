How to subscribe

  1. Create a subscription. Its address is shown once, at the top of this page.
  2. Copy the address.
  3. In Outlook, choose Add calendar, then Subscribe from web (or From internet), and paste it.

Treat the address like a password: anyone who has it sees these dates. Revoke it if it leaks.
